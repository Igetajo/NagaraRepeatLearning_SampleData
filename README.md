# NagaraRepeatLearning_SampleData
Sample data for Nagara Repeat Learning Kindle book.

# ながらリピート学習 Kindle版 サンプルデータ

このリポジトリには、Kindle書籍『脳科学的に正しい　ながらリピート学習』で紹介されているサンプルデータが含まれています。

## ダウンロード方法
以下のリンクをクリックすると、一括でダウンロードできます。
[sample_en-ja.zipをダウンロード](https://github.com/Igetajo/NagaraRepeatLearning_SampleData/raw/refs/heads/main/sample_en-ja.zip)

または、このページ上部の緑色の「Code」ボタンをクリックし、「Download ZIP」を選択して、全てのリポジトリファイルをダウンロードすることも可能です。

## 内容
* `01.mp3`: 音声データのサンプルです。20個の見出し語に対して、「見出し語」→「母国語訳」→「フレーズ」→「母国語訳」の順で収録しています。巻末に付録として単語帳を掲載しておりますのでご参照ください。
* `Folder.jpg`: 音声を分割した後のMP3形式ファイルで使用されるジャケット画像です。
* `make.txt`: 音声データを無音部分で分割する魔法のスクリプトです。メモ帳で編集できるように拡張子を「txt」にしてありますが、中身はスクリプトファイルです。
* `review`: 音声データの分割ファイルが入っています。ながらリピート学習を体験するためのデータです。

本書の手順に従ってご利用ください。
